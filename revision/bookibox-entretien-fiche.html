5. Questions tech probables

TypeScript vs JavaScript ?

TS = typage statique → moins d’erreurs, meilleur refactor sur une grosse codebase.

API REST ?

Endpoints HTTP (GET / POST / PUT / DELETE), JSON, contrats clairs entre front et back.

PostgreSQL / schéma ?

Tables liées (livres, stocks, commandes, clients…). Migrations quand le modèle évolue.

Comment tu debug ?

Reproduire → logs / DevTools → isoler (front vs API vs BDD) → fix → retester le parcours.

Docker ?

Même environnement local / prod ; app + dépendances packagées.

Dilicom / ISBN ?

« Je n’ai pas encore touché Dilicom, mais je comprends l’idée : enrichir les fiches livres via une source biblio externe (ISBN / EAN). J’ai déjà travaillé avec des APIs et des modèles de données. »
